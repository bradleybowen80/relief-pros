# 02-website

The public site and landing pages: code, copy drafts, and deploy notes.

## What belongs here

- Site source code (when built, likely as a subfolder per site or page)
- Landing page copy drafts before they go live
- Deploy and hosting notes (registrar, DNS, host, how to publish)

## Hard gate before anything ships

Every page must pass the Texas naming rule in [CLAUDE.md](../CLAUDE.md):
"bookkeeping" everywhere, never "accountant," "accounting," or "auditor."
Also confirm no page offers an excluded service (tax prep, payroll, AP/AR)
and that pricing copy reflects ACH autodraft on the 1st, not invoicing.
