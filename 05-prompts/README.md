# 05-prompts

Standing instructions and reusable prompts for Claude. When Brad says "run the
onboarding prompt" or drops in new instructions for how to work on this
business, they land here.

## Rules

- One file per prompt or instruction set, named for what it does
  (for example `draft-cold-email.md`, `monthly-close-review.md`).
- Each file states: when to use it, the prompt itself, and what a good output
  looks like.
- Prompts inherit the hard rules in [CLAUDE.md](../CLAUDE.md) automatically.
  A prompt never needs to restate them, and no prompt may override them.
